DROP SCREENSHOTS IN HERE
========================

The site is already wired for these four. Save them under exactly these
names and they appear on their own — nothing else needs doing:

    hud-bars.png     the minimap with the needs down the left
                     and the fuel gauge on the right
                     -> shows on Bare Minimum AND on Fumes

    fumes-pump.png   the forecourt panel, mid-fill
                     -> Fumes

    posted-up.png    Gerald, and a line to answer
                     -> Hoodrich

    armoury.png      Stretch's table, a gun picked out
                     -> Hoodrich

png or jpg both work — if you save jpg, say so and the extensions get
flipped. 1600px wide is plenty; the frame they sit in is about 62
characters across, so anything bigger is bytes for nothing.

A name that is not in the list above is ignored until it gets wired up,
and a name in the list that has no file shows nothing at all — no broken
image, no empty frame. So half of them landing is fine.
